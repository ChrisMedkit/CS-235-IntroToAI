## Summary
CS235 "Personal Interest Website with an LLM": build a multi-page site with an LLM as a development
partner, commit after every step, and keep a prompt log. This version was a play-money tennis
"sportsbook" that replays 2023 Wimbledon matches with public-model win chances, plus blackjack and slots.

## Direction & class methods
- **Vision:** sportsbook look; home page with banner, sport/mode picker and match replay; subpages for the model, mini games and Play Safe.
- **Process:** brainstorm → design spec → plan → build task by task with tests → fresh code review → fixes.
- **In-class methods & notation to follow:** semantic HTML, one shared CSS file, one shared JS file, commit per step, prompt log.
- **Constraints:** static site (GitHub Pages), play money only.
